# 🚕 Uber Ride Business Analytics Dashboard

## 📌 Project Overview

This project focuses on analyzing Uber ride data and building an interactive **Business Analytics Dashboard using Microsoft Excel and Power BI**.

The objective was not only to analyze revenue, but also to understand the operational side of the ride business — where rides are happening, how far customers are travelling, and how customers and drivers are rating the experience.

The dashboard provides insights into ride performance, revenue, vehicle types, locations, riders, and operational trends.

---

## 🎯 Project Objectives

- Analyze overall Uber ride performance
- Understand revenue and booking trends
- Analyze ride distance and customer travel patterns
- Compare different vehicle types
- Identify high-performing locations
- Analyze customer and driver ratings
- Understand rider and trip behavior
- Build an interactive dashboard for business decision-making
